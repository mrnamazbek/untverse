# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **UNTverse** and student code execution environments seriously.

If you discover a security vulnerability (such as sandbox escape, authentication bypass, or data leakage), please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to the security team at `security@untverse.kz` or contact the maintainer directly.
3. Include detailed reproduction steps, proof of concept, and the environment tested.

### What to expect

- **Initial acknowledgment**: within 24 hours.
- **Triage and severity assessment**: within 48 hours.
- **Fix deployment and advisory release**: based on vulnerability severity.

Thank you for helping keep UNTverse secure for all students and educators.
